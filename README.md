# 🦀 Ferrish

> A minimal shell written in Rust - because every aspiring systems programmer should build one.

![Rust](https://img.shields.io/badge/rust-%23000000.svg?style=flat&logo=rust&logoColor=white)

## Features

- **Built-in Commands** — `cd`, `pwd`, `echo`, `type`, `exit`
- **Pipeline Support** — chain commands with `|`, including builtins in pipes
- **Tab Completion** — single-tab auto-complete, double-tab listing with common prefix expansion
- **Interactive Input** — raw mode with Ctrl+C (interrupt), Ctrl+D (exit), backspace, quoted arguments
- **External Commands** — `PATH`-based resolution and execution
